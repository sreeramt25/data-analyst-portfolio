# Sreeraman T — Data Analyst Portfolio

A responsive, static portfolio website built with HTML and CSS.

## Deploy on Netlify

1. Create a GitHub repository named `data-analyst-portfolio`.
2. Upload `index.html` and this `README.md` to the repository root.
3. In Netlify, choose **Add new project → Import an existing project**.
4. Connect GitHub and select `data-analyst-portfolio`.
5. For this static site, leave the build command empty and set the publish directory to `.` (repository root), if Netlify asks for it.
6. Select **Deploy**. Netlify will provide a public `*.netlify.app` URL.
7. Open the public URL and test the project links, email link, mobile layout, and Power BI PDF report link.

Future commits to the connected GitHub repository can trigger automatic deployments.
